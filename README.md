# WT Tactical Map (v1.0) — 《战争雷霆》多端局域网战术副屏

面向《战争雷霆》陆战历史模式（RB）的自托管局域网「战术副屏」Web 工具。
**零内存读取、零注入、零修改游戏文件**——仅通过《战争雷霆》官方内置的本机只读遥测接口 `http://127.0.0.1:8111/` 获取当前战局态势，启动后可在**电脑外接副屏、手机、平板**浏览器实时查看、缩放、触屏标点与测距。

---

## 一、v1.0 核心特性

### 1. 底图防缓存与指纹识别
- **换局/退回机库自动清缓存**：离开训练场或上一局进入机库时，后端立即清空旧底图字节与签名缓存，彻底解决“排进新图仍残留上一局/训练场底图”的问题；图像接口统一附加 `no-store, no-cache, must-revalidate` 响应头。
- **自动指纹绑定与手动切图**：对 `map_img` 计算 SHA-256 指纹并结合物理边界匹配，首次进图一键绑定即可永久秒切；也支持在侧边栏下拉框随时手动切换预设地图底图与走线。

### 2. 战局可视优化（贴合陆战实战）
- **有效交战区自动聚焦**：针对外围包含大片荒野的地图（如诺曼底、欧洲省、北荷兰省等），进图时根据占领点与坦克出生点包围盒自动放大居中到核心交战区；仍可随时用滚轮自由缩放，或按 **`R` 键**在「交战区聚焦 ↔ 100% 全图」之间切换。
- **紧凑出生点与分段尾迹**：出生点改为随缩放自适应的小巧半透明菱形/三角，不再糊成一片；玩家行进尾迹改为多段结构，阵亡复活或换车重生时自动断线并重置插值起点，绝不把阵亡点与新复活点连成跨图直线。
- **可选「车头朝上」平滑模式（`N` 键）**：开启跟随玩家后，地图随车头平滑旋转（拖拽/捏合期间自动冻结旋转防抖，文字标签始终保持正立）。
- **低眩光多端适配**：深色低眩光 HUD，自动适配电脑副屏、手机竖屏/横屏、刘海/底部地址栏安全区（`env(safe-area-inset-*)`）；手机端支持单指拖拽、双指捏合缩放、**长按地图 0.5 秒**设置/清除临时路标。

### 3. 实时测距与小键盘盲操切换
- 实时计算玩家当前位置到锁定目标的**直线距离（米）**与**相对车头钟点方位**（如 `右前 2点 (+48°)`，在车头朝上模式下与屏幕左右方向完全一致）。
- **精简候选目标**：已移除占领点（A/B/C）干扰，陆战历史模式下聚焦于**用户自定义战术标点**与**临时路标**（按距玩家由近到远排序）；若在街机或特定事件下 `8111` 下发了点亮敌军或小队标点，也会自动纳入测距列表。
- **盲操控制通道**：
  - 浏览器聚焦时支持 `Tab` / `Shift+Tab` 与小键盘按键；
  - 若本机安装 `pynput`（管理员权限下可在全屏/无边框游戏窗口前台直接响应），可通过小键盘直接盲操切换副屏测距目标，无需切出游戏窗口：
    - 小键盘 **`+` / `4`**：锁定 / 切下一个目标
    - 小键盘 **`-` / `1`**：切上一个目标
    - 小键盘 **`/` / `0`**：取消锁定

### 4. 战术走线、透明图层与 `WTMAP://` 分享码
- **副屏在线绘制**：支持画折线箭头、插架枪卡点、画高危交火区圆圈，保存至本地 `routes/routes_config.json`（每次写入前自动在 `routes/backups/` 生成时间戳备份）。
- **`WTMAP://` 战术分享码**：零后端存储，纯前端压缩编码 + CRC32 校验，一键复制当前地图走线与标点并在手机/电脑或队友间导入互传。
- **外部 PNG 与开源地图库**：支持将透明 PNG 放入 `routes/overlays/` 叠加；已通过 `scripts/import_workbench.py` 收录 56 张陆战地图元数据与参考走线。

## 二、快速启动

### 环境要求
- Python 3.10+（**纯标准库零第三方依赖**，开箱即用）
- 可选：`pip install pynput`（仅用于在游戏窗口前台时启用全局小键盘盲操热键；未安装时服务自动优雅降级，不影响其他功能）

### 启动方式
1. **实战模式（监听 `0.0.0.0:8123`，连接游戏 `8111` @ 8Hz）**：
   - 双击 `start.bat`，或终端运行：
     ```powershell
     python server.py
     ```
   - 终端会打印本机访问地址（`http://127.0.0.1:8123`）以及同一 Wi-Fi 下手机/平板可直接打开的局域网地址（如 `http://192.168.x.x:8123`）。
2. **离线演示 / 预编辑模式（无需启动游戏）**：
   ```powershell
   python server.py --mock
   ```

| 平台 | 操作 / 按键 | 说明 |

## 四、`8111` 接口机制说明与自检工具

> **重要说明（请勿误解为工具漏画）**：
> 在《战争雷霆》**陆战历史模式（RB）**下，游戏客户端内置的 `http://127.0.0.1:8111/map_obj.json` 受官方服务端规则限制，**不会直接下发未点亮的敌方载具坐标，且常规小队/队友地图 Ping 多数情况下也不会出现在该 JSON 中**（即使游戏内小地图因侦察短暂闪红，接口往往仍会过滤）。本工具严格遵守官方只读接口边界，绝不读取内存或注入进程。

如需确认当前对局中 `8111` 接口实际输出了哪些原始对象，可随时运行自带诊断脚本：
```powershell
# 查看当前一帧的 map_obj.json 分类统计与关键对象
python scripts/inspect_8111_objects.py

# 持续监听 20 秒（4Hz），一旦出现敌军/侦察/闪烁/标点对象立即打印
python scripts/inspect_8111_objects.py --watch 20
```

## 五、维护说明与 v2.0 方向（欢迎 Fork / 魔改）

> **维护说明**：v1.0 自用已基本毕业，本项目纯属顺手开源分享。个人精力有限，**不接定制需求、不卷高频修 Bug、不保证持续维护**。

目前 v1.0 已经把底层框架、`8111` 遥测解析、地图识别与基础交互地基搭通，整体界面偏理工科实用风。**非常欢迎有审美、懂交互的设计/前端大佬直接 Fork 魔改，或基于这套地基继续打造更帅的 v2.0 战术面板。**

既然陆战历史模式下官方 `8111` 不会给出“虚空敌方坐标”，v2.0 的核心方向建议转向**基于合法友军信息反推战场态势与局后复盘**：
1. **战局事件与轨迹后台录制**：按局持久化记录 8Hz 友军分布、占领点状态变化、速度与玩家轨迹，形成轻量本地战局日志。
2. **友军阵亡/消失坐标与时间推演**：通过追踪存活友军在战局中的突然消失/阵亡坐标与时间窗口，自动汇总**友军阵亡热点区域**，识别**战线缺口与敌方推进趋势**。
3. **重生决策辅助、局后复盘与 UI 重塑**：在副屏上结合友军阵亡热点与战区归属提供二次重生路线避险提示，支持局后按时间轴倍速回放整局态势，并进一步打磨战术 HUD 与视觉表现。
