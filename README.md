# 基米战术面板 v2.0 — 《战争雷霆》Go 单文件多端战术副屏

面向《战争雷霆》陆战历史模式（RB）的自托管局域网「战术副屏」工具（v2.0 已重构为 **Go 单文件可执行程序**，内嵌前端页面、56 张地图资源、本地化 BWiki 兵种 SVG 图标与专属「基米二次元版」角色立绘，双击 `WT_Tactical_Map.exe` 即可零环境依赖运行）。
**零内存读取、零注入、零修改游戏文件**——仅通过《战争雷霆》官方内置的本机只读遥测接口 `http://127.0.0.1:8111/` 获取局内公开坐标与状态，支持电脑外接副屏、手机、平板实时查看。

---

## 一、v2.0 核心特性

### 1. Go 单文件 `embed` 打包，零依赖双击即用
- 后端由 Python 迁移至 Go（纯标准库，零第三方依赖），使用 `//go:embed` 将 `web/` 页面、5 张本地化陆战兵种 SVG 图标及 `routes/routes_config.json`（56 张地图数据与参考走线）全部打入单个 `WT_Tactical_Map.exe`（约 9.6 MB）。
- 内置 Win32 全局小键盘监听（`GetAsyncKeyState`），无需额外安装 Python/pynput 即可在游戏窗口前台响应小键盘目标切换。
- 支持 `--mock` 离线演习模式、`--port` 自定义端口、`--dev` 开发热读磁盘静态资源。

### 2. 自定义战术图标与己方型号标注
- 本地化打包 War Thunder BWIKI 5 类陆战兵种 SVG 图标（`WT_type_ground_light_tank.svg`、`medium_tank`、`heavy_tank`、`tank_destroyer`、`spaa`），无运行时外链请求。
- 画布单位采用**圆形外框 + 切线方向三角指示尖角**设计：外圈与尖角随 `(dx, dy)` 方向向量实时旋转指向行进/朝向方位；内部兵种 SVG 图标与己方主视角短型号标签（如 `M18`、`M41A1`、`T34`、`M56`，通过 `/indicators` `type` 映射）始终保持水平正立。

### 3. 己方阵亡残骸留痕与多队友残骸标黄高危区
- **己方阵亡原地留专属残骸**：检测到主视角载具从存活变为失效/离场时，在最后有效坐标持久化留下高对比度己方残骸标记（标注序号与阵亡载具型号），支持一局多次重生累计保留，换局或退回机库自动清空。
- **多队友阵亡残骸重叠标黄**：记录阵亡坐标与时间窗口，当同一片区（默认残骸影响半径 `80m`，侧边栏 `40~200m` 可调）内多名单位阵亡且影响范围重叠时，自动高亮标黄提示高危交火区。
- **近距友军消失高光 + RWR 风格警示音**：警戒半径内地面友军突然消失时，画布亮起脉冲光圈与相对方位，同时合成空战 RWR 风格急促脉冲提示音（带冷却防连响，侧边栏可一键静音与试听）。

### 4. 三档动态路线推荐、动态交战前线与曲线绘制
- **三档动态路线推荐（关 / 保守 / 平衡 / 激进）**：结合自身载具类型、各战线存活队友兵种分布与标黄残骸高危区，在预设走线图中动态高亮推荐路线并输出简短战术提示（保守档依托重/中坦主力二线；平衡档兼顾半侧翼交叉火力与回防；激进档面向高机动载具大纵深穿插并避开残骸死区）。
- **自动计算动态前线**：结合存活己方载具推进前沿（降低防空车权重）、夺控点归属与可见目标分布，动态绘制时间平滑的交战前线带。
- **走线画板支持曲线模式**：新增多控制点平滑插值**曲线**绘制，支持撤销与一键清空当前图层，并兼容 `WTMAP://` 战术分享码导入导出。

### 5. 双轨对局打分、历史分数波动与「基米二次元版」主题
- **双轨对局打分与波动走势**：未接入 AI 时，对局结束自动按内置确定性规则计算本局得分并持久化至本地；提供历史对局得分表格、Canvas 分数波动趋势图与「复制战绩摘要」纯文本导出。
- **可选主动调用外部 AI API**：可在设置中配置自定义 OpenAI 兼容接口（Base URL、API Key、Model）；启用后仅由本工具主动向外请求 AI 结合近期历史给出本局评分与评语（不提供对外被接入的 API 或在线排行榜服务）。
- **双主题切换（「默认战术」/「基米二次元版」）**：提供契合猫耳角色设定的蓝紫星辉深空主题与柔边渐隐专属角色图（通过 Go `embed` 打包），配合半透明底衬保证地图路线、前线、残骸黄标与载具图标的高对比度可读性。

### 6. 目标定位切换、交战区聚焦与整活彩蛋
- **底图防缓存与交战区聚焦**：换局/退回机库自动清空旧底图与签名缓存；进图自动放大聚焦核心交战区（`R` 键切换交战区 ↔ 100% 全图）。
- **小键盘盲操目标方位切换**：实时显示锁定目标的相对方向与点位（支持 `Tab` / `Shift+Tab`、小键盘 `+`/`4`、`-`/`1`、`//0`）。
- **整活彩蛋「一键获胜」**：侧边栏底部内置纯前端彩蛋按钮，点击后弹出仿系统确认框，选择「确认卸载（彻底解脱）」后不会执行任何真实文件删除或卸载操作，而是弹出趣味结算框并附带直达官网的下载入口。

## 二、快速启动与编译

### 直接运行（推荐）
- 双击 `WT_Tactical_Map.exe` 或 `start.bat` 即可启动（默认监听 `0.0.0.0:8123`，控制台打印本机及局域网手机访问地址）。
- 离线预览 / 无游戏测试：
  ```powershell
  .\WT_Tactical_Map.exe --mock
  ```

### 从源码自行编译（Go 1.24+）
```powershell
go build -ldflags="-s -w" -o WT_Tactical_Map.exe .
```

## 三、`8111` 接口机制说明与项目声明

> **接口说明**：在《战争雷霆》**陆战历史模式（RB）**下，客户端内置的 `http://127.0.0.1:8111/map_obj.json` 受官方规则限制，不会直接下发未点亮的敌方载具坐标，常规队友地图 Ping 多数也不会输出。本工具严格遵守官方只读接口边界。

> **项目定位声明与暂不实现项**：
> - 本版本纯粹是个人想做、顺便消耗模型额度折腾的自用/分享小版本，个人精力有限，**不承诺长期维护或逐条修 Bug**，非常欢迎有审美、懂交互的设计/前端大佬直接 Fork 魔改。
> - **暂不实现项**：暂不实现榴弹炮专用模式与自动抛射计算。
