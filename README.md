# 基米战术面板 v2.0 — 《战争雷霆》Go 单文件多端战术副屏

面向《战争雷霆》陆战历史模式（RB）的自托管局域网「战术副屏」工具。v2.0 已重构为 **Go 单文件可执行程序**，内嵌前端页面、56 张地图资源、本地化 BWIKI 兵种 SVG 图标与专属「基米二次元版」角色立绘，双击 `WT_Tactical_Map.exe`（约 14 MB）即可零环境依赖运行。

**零内存读取、零注入、零修改游戏文件**——仅通过《战争雷霆》官方内置的本机只读遥测接口 `http://127.0.0.1:8111/` 获取局内公开坐标与状态，支持电脑外接副屏、手机、平板实时查看。

## 一、v2.0 核心特性

### 1. Go 单文件 `embed` 打包，零依赖双击即用
- 后端由 Python 迁移至 Go（纯标准库，零第三方依赖），使用 `//go:embed` 将 `web/` 页面、5 张本地化陆战兵种 SVG 图标、基米二次元版角色立绘及 `routes/routes_config.json` 全部打入单个 `WT_Tactical_Map.exe`。
- 内置 Win32 全局小键盘监听（`GetAsyncKeyState`），无需额外安装 Python 或第三方库即可在游戏窗口前台响应小键盘目标切换。
- 支持 `--mock` 离线演习模式、`--port` 自定义端口、`--no-browser` 无头启动、`--dev` 开发热读磁盘静态资源。

### 2. 双 UI 主题切换（经典战术版 / 基米二次元版）
- 侧边栏顶部支持一键切换 **默认战术（经典战术版）** 与 **基米二次元版**，偏好自动持久化至浏览器 `localStorage`：
  - **经典战术版**：高对比度深空战术面板风格，适合长时间专注读图。
  - **基米二次元版**：蓝紫渐变与星辉深空主色调，搭配经 Go `embed` 打包的柔边渐隐专属猫耳角色立绘；地图画布、矢量路线、三档推荐路线、前线带、残骸黄标与载具图标均保留半透明高对比底衬，不遮挡战局信息。

### 3. 自定义战术图标、己方型号标注与残骸高危区
- 本地化打包 War Thunder BWIKI 5 类陆战兵种 SVG 图标（`WT_type_ground_light_tank.svg`、`medium_tank`、`heavy_tank`、`tank_destroyer`、`spaa`），无运行时外链请求。
- 画布单位采用**圆形外框 + 切线方向三角指示尖角**设计：外圈与尖角随 `(dx, dy)` 方向向量实时旋转指向行进/朝向方位；内部兵种 SVG 图标与己方主视角短型号标签（如 `M18`、`M41A1`、`T34`、`M56`，通过 `/indicators` `type` 映射）始终保持水平正立。
- **己方阵亡原地留专属残骸**：检测到主视角载具从存活变为失效/离场时，在最后有效坐标留下高对比度己方残骸标记（标注序号与阵亡载具型号），支持单局多次重生累计保留，换局或退回机库自动清空。
- **多队友阵亡残骸重叠标黄**：当同一片区（默认半径 `80m`，侧边栏 `40~200m` 可调）内多名单位阵亡且影响范围重叠时，自动高亮标黄提示高危交火区。
- **近距友军消失高光 + RWR 风格警示音**：警戒半径（`40~300m` 可调）内地面友军突然消失时，画布亮起脉冲光圈与相对方位，同时合成空战 RWR 风格脉冲提示音（支持静音与试听）。

### 4. 三档动态路线推荐、动态前线与画线/曲线/椭圆工具
- **三档动态路线推荐（关 / 保守 / 平衡 / 激进）**：结合自身载具类型、各战线存活队友兵种分布与标黄残骸高危区，动态高亮推荐路线并输出战术提示。
- **自动计算动态前线**：结合存活己方载具推进前沿（降低防空车权重）、夺控点归属与可见目标分布，绘制时间平滑的交战前线带。
- **矢量射界箭头视觉优化**：黄色射界/观察方向箭头内置最大渲染长度上限（默认归一化 `0.14`）与末端渐隐透明效果，保留清晰方向指示的同时避免长直线横穿建筑遮挡街区地形。
- **交互式画线工具（折线 / 曲线 / 椭圆 / 卡点 / 交火区）**：
  - 支持多点**折线**、Catmull-Rom 平滑**曲线**、拖拽绘制**椭圆**（按住 `Shift` 等比正圆，按住 `Alt` 从中心向外扩散）、**卡点**标记与**交火区**圆圈，支持撤销、单元素删除与清空当前图层。
  - 兼容 `WTMAP://` 战术分享码一键编码复制与导入解析。
  - **一键固化为本地默认预设**：点击侧边栏「**保存为当前地图默认预设**」，可将当前手绘或导入的折线/曲线/椭圆直接持久化至 `routes/routes_config.json` 并自动开启图层勾选，下次切换该地图时自动加载显示（适合补充上游缺失走线的地图）。

### 5. 双轨对局打分、历史分数波动与可选外部 AI 复盘
- **离线确定性打分与波动统计**：对局结束（或手动点击「结算本局」）后，按内置规则记录地图、载具、时长、机动距离、最高时速、阵亡与近距友军损失，计算本局得分并持久化至 `routes/match_history.json`；弹窗内提供历史得分表格、分数波动趋势图及「**复制战绩摘要**」纯文本导出。
- **可选主动调用外部 AI API**：可在设置中配置 OpenAI 兼容接口（`Base URL`、`API Key`、`Model`）；启用后由本工具主动向外请求 AI 结合本局表现与近期历史记录综合评分并生成战局评语（本工具不提供对外被接入的 API 或多人在线排行榜服务器）。

### 6. 本地底图缓存、加载稳定性与整活彩蛋
- **多级底图缓存与并发去重**：
  - 后端 `/api/preset_map_img` 优先读取内存缓存与本地磁盘缓存目录 `routes/map_cache/`，已缓存底图秒出；内置 `inflight` single-flight 请求合并，避免同一地图并发重复拉取。
  - 远端拉取设置严格超时（2s 建连、3.5s `base_url` 超时、3.0s `thumbnail_urls` 自动回退），并在服务启动后后台轻量预热常见预设地图。
  - 前端维护最多 32 张已解码 `Image` LRU 内存缓存、7 秒加载超时与失败提示条，并在底图加载完成前门控矢量/PNG 走线渲染，防止路线先于底图孤立浮现。
- **整活彩蛋「一键获胜」**：侧边栏底部内置纯前端盲盒跳转彩蛋，点击确认后不会执行任何真实卸载或文件删除操作，仅弹出趣味结算窗并随机开启下一站链接。

## 二、快捷键与手势列表

### PC 端快捷键
| 操作 / 按键 | 功能说明 |
| :--- | :--- |
| **鼠标滚轮** | 以光标为中心缩放地图（默认进图自动居中完整适配或聚焦交战区） |
| **左键拖拽 / 双击** | 平移地图 / 双击快速复位视图 |
| **点击敌军或标记** | 锁定目标并实时显示相对距离与点位（点击空白处取消） |
| **Tab / Shift + Tab** | 顺/逆序循环切换锁定目标 |
| **小键盘 `+` / `-` / `/`**（或 `4` / `1` / `0`） | 前台/后台全局切换或取消锁定目标（游戏窗口内同样生效） |
| **Ctrl + 左键** 或 **鼠标中键** | 在地图上放置/移动临时战术路标 |
| **`H`** | 隐藏 / 显示右侧控制栏 |
| **`N`** | 切换「车头朝上」旋转模式 |
| **`F`** | 切换浏览器全屏 |
| **`R`** | 复位视图（在交战区聚焦与 100% 全图之间切换） |
| **`C`** | 清除临时战术路标 |
| **绘图：`Shift` 拖拽** | 椭圆工具模式下锁定等比正圆 |
| **绘图：`Alt` 拖拽** | 椭圆工具模式下从中心向四周扩散绘制 |
| **绘图：`空格` / 中键拖拽** | 绘制状态下临时平移画布 |

### 手机 / 平板触控手势
| 手势 | 功能说明 |
| :--- | :--- |
| **单指拖拽** | 平移地图 |
| **双指捏合** | 缩放地图 |
| **轻点敌军 / 标记** | 锁定目标并查看相对方位 |
| **长按地图 0.5 秒** | 设置或清除临时战术路标 |
| **右上角悬浮按钮** | 展开或收起控制面板 |

## 三、快速启动与编译

### 直接运行（推荐）
- 双击 `WT_Tactical_Map.exe` 或 `start.bat` 即可启动（默认监听 `0.0.0.0:8123`，控制台打印本机及局域网手机访问地址）。
- 离线演习 / 无游戏调试：
  ```powershell
  .\WT_Tactical_Map.exe --mock
  ```

### 从源码自行编译（Go 1.24+）
```powershell
go vet ./...
go build -ldflags="-s -w" -o WT_Tactical_Map.exe .
```

## 四、`8111` 接口机制说明与项目声明

> **接口说明**：在《战争雷霆》**陆战历史模式（RB）**下，客户端内置的 `http://127.0.0.1:8111/map_obj.json` 受官方规则限制，不会直接下发未点亮的敌方载具坐标，常规队友地图 Ping 多数也不会输出。本工具严格遵守官方只读接口边界。

> **项目定位声明与暂不实现项**：
> - 本版本纯粹是个人折腾与分享的小工具，个人精力有限，**不承诺长期维护或逐条修 Bug**，欢迎直接 Fork 魔改。
> - **暂不实现项**：暂不实现榴弹炮专用模式与自动抛射计算。
