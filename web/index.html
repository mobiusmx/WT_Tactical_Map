操作提示
  • 滚轮：光标为中心缩放
  • 左键拖拽：平移地图（双击复位）
  • 点击敌军/标记：锁定测距（点空白取消）
  • Tab / Shift+Tab：循环切换测距目标
  • 小键盘 + - /（或 4 1 0）：切换/取消测距目标
  • Ctrl+左键 / 中键：放置临时战术路标
  • H：隐藏/显示右侧控制栏　N：车头朝上
  • F：全屏　R：复位　C：清除路标
  • 单指拖拽：平移地图
  • 双指捏合：缩放地图
  • 轻点敌军/标记：锁定测距与方位
  • 长按地图 0.5 秒：设置 / 清除临时路标
  • 右上角按钮：收起或展开控制面板
